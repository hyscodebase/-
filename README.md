# 일어나! 기지개 알림

오래 앉아 있는 시간을 줄이기 위해 기본 50분마다 Chrome 알림을 보내는 Manifest V3 확장 프로그램입니다. 실제 확장 패키지는 [일어나 폴더](%E1%84%8B%E1%85%B5%E1%86%AF%E1%84%8B%E1%85%A5%E1%84%82%E1%85%A1)에 있습니다.

## 기능

- 남은 시간 표시, 일시정지·재시작·타이머 초기화
- 5~180분 사이의 알림 간격 설정
- 알림에서 10분 뒤 다시 알리기
- 브라우저 재시작 후 상태 복구와 오늘의 알림 횟수 표시
- 테스트 알림으로 운영체제 알림 설정 확인

## 설치

1. 이 저장소를 내려받고 압축을 해제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 저장소 안의 **일어나** 폴더를 선택합니다.
5. 확장 아이콘을 툴바에 고정한 뒤 **테스트 알림 보내기**를 눌러 확인합니다.

설치 직후 기본 타이머가 시작됩니다. 알림이 보이지 않으면 운영체제의 Chrome 알림 허용 여부를 확인하세요. Chrome이 완전히 종료된 동안에는 알림을 표시할 수 없습니다.

Node.js가 설치되어 있다면 저장소 루트에서 다음 테스트를 실행할 수 있습니다.

```bash
node --test '일어나/tests/background.test.js'
```

사용 권한은 `alarms`, `notifications`, `storage`이며 타이머 상태는 `chrome.storage.local`에 저장합니다.
