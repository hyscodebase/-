# 일어나! 기지개 알림

오래 앉아 있지 않도록 기본 **50분마다** 크롬 알림을 보내는 Manifest V3 확장 프로그램입니다.

## 설치

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더(`일어나`)를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **일어나! 기지개 알림**을 고정하면 편합니다.

설치 직후부터 50분 타이머가 시작됩니다. 확장 프로그램 아이콘을 누르면 Chrome 기본 팝업으로 타이머가 열립니다. 팝업의 **테스트 알림 보내기**로 알림 권한과 운영체제 설정을 바로 확인할 수 있습니다.

## 기능

- 기본 50분 간격 알림
- 남은 시간 실시간 표시
- 타이머 일시정지, 재시작, 처음부터 다시 시작
- 5~180분 사이의 알림 간격 설정
- 알림에서 “10분 뒤에 다시” 선택
- 크롬 재시작 후 타이머 상태 복구
- 오늘 보낸 기지개 알림 횟수 표시

## 알림이 보이지 않을 때

- 팝업에서 **테스트 알림 보내기**를 눌러 봅니다.
- macOS에서는 **시스템 설정 → 알림 → Google Chrome**에서 알림을 허용합니다.
- Windows에서는 **설정 → 시스템 → 알림 → Google Chrome**을 허용합니다.

크롬이 완전히 종료된 동안에는 알림을 표시할 수 없습니다. 예정 시간이 지난 뒤 크롬을 다시 열면 Chrome Alarms 정책에 따라 알림이 다시 처리됩니다.
